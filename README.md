# Predator–Prey Modelling (CITS4403 Project)

**Authors:** Su-Yeon Yang, Jiaren Zhu
**Date:** 2025-10-01

# Project Overview

This project investigates how predator and prey population interact under different conditions through different modelling approaches. It provides a comparative analysis and a generalised insight into how spatial heterogeneity and behavioural adaptation influence predator-prey dynamics highlighting their interaction patterns across deterministic and stochastic models. Time‑series behaviour, confidence intervals, and extinction probabilities are compared across multiple random seeds under equivalent conditions. Results demonstrate that refugia and adaptive responses dampen oscillation amplitudes and reduce extinction risk for prey; hence improving overall persistence compared to the homogeneous, non‑adaptive baseline.
