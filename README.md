# Predator–Prey Modelling (CITS4403 Project)

**Authors:** Su-Yeon Yang, Jiaren Zhu
**Date:** 2025-10-01

# Project Overview

This project investigates how predator and prey population interact under different conditions through different modelling approaches. 

# Setup

## Create and activate a virtual environment

```bash
python3 -m venv venv
source venv/bin/activate
```

## Install Dependencies

```bash
pip install -r requirements
```

## Launch notebook

```bash
jupyter notebook
```
